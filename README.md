# Luxe Touch Beauty Studio

A responsive salon landing page concept with a services menu and one-tap WhatsApp booking.

**Live demo:** https://mattsunny-dev.github.io/salon-concept/

## Features
- Hero section with a "Book on WhatsApp" button
- Services with prices in naira: hair, braids, makeup, nails and lashes
- A Book button on every service that opens WhatsApp with the booking message ready
- Opening hours, about section and sample reviews
- Mobile-friendly layout

## Built with
HTML, CSS and JavaScript. Hosted on GitHub Pages.

## Note
This is a concept project with sample content. It can be customized with a salon's name, services, prices, photos and WhatsApp number.
